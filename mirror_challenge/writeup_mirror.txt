## Introduction

Le challenge nous donne un binaire ELF 64-bit strippé qui vérifie un flag selon deux "lois" cryptographiques. Le flag est divisé en deux parties qui sont transformées différemment avant d'être comparées avec des données chiffrées.

---

```bash

```

Le programme demande un flag au format `Securinets_fst{...}` et indique quelle loi est violée.

## Analyse Statique avec Ghidra

### Fonction main (FUN_00401894)

La fonction principale fait les opérations suivantes:

1. Initialise deux matrices avec des seeds fixes:
   - `init_matrix_a(0xDEADBEEF)`
   - `init_matrix_b(0xCAFEBABE)`

2. Calcule deux clés dynamiquement:
   - `KEY_1 = derive_key_1()`
   - `KEY_2 = derive_key_2()`

3. Lit l'input et vérifie les deux parties:
   - `check_part_1(input, L_1, KEY_1)`
   - `check_part_2(input + L_1, L_2, KEY_2)`

Variables importantes:
- `DAT_00404060` : longueur de la partie 1 (L_1)
- `DAT_00404068` : longueur de la partie 2 (L_2)
- `DAT_00404040` : adresse des données chiffrées D_1
- `DAT_00404050` : adresse des données chiffrées D_2

### Fonction check_part_1 (FUN_004015af)

```c
// Reverse l'input
for (i = 0; i < L_1; i++) {
    temp[i] = input[L_1 - 1 - i];
}

// Applique Law 1 + XOR + Compare
for (i = 0; i < L_1; i++) {
    transformed = apply_law_1(temp[i]);
    if ((transformed ^ KEY_1) != D_1[i]) {
        return 0;
    }
}
```

Cette fonction:
1. Inverse l'ordre des caractères
2. Applique une transformation (Law 1)
3. XOR avec KEY_1
4. Compare avec D_1

### Fonction apply_law_1 (FUN_004014e7)

```c
if ((c >= 0x61) && (c <= 0x7a)) {
    return ((c - 0x61 + 13) % 26) + 0x61;
}
else if ((c >= 0x41) && (c <= 0x5a)) {
    return ((c - 0x41 + 13) % 26) + 0x41;
}
return c;
```

C'est ROT13:
- Décalage de 13 pour les lettres minuscules (a-z)
- Décalage de 13 pour les lettres majuscules (A-Z)
- Les autres caractères ne changent pas

### Fonction check_part_2 (FUN_00401680)

```c
for (i = 0; i < L_2; i++) {
    transformed = apply_law_2(input[i], i);
    if ((transformed ^ KEY_2) != D_2[i]) {
        return 0;
    }
}
```

Cette fonction:
1. Applique une transformation (Law 2) qui dépend de la position
2. XOR avec KEY_2
3. Compare avec D_2

Pas de reverse cette fois.

### Fonction apply_law_2 (FUN_00401564)

```c
result = swap_nibbles(c);
if (position % 2 == 1) {
    result = reverse_bits(result);
}
return result;
```

Cette fonction:
1. Swap les nibbles (4 bits hauts avec 4 bits bas)
2. Si position impaire, inverse les bits

### Fonctions auxiliaires

**swap_nibbles:**
```c
return (x << 4) | (x >> 4);
```

**reverse_bits:**
```c
result = 0;
for (i = 0; i < 8; i++) {
    result = (result << 1) | (x & 1);
    x >>= 1;
}
return result;
```

## Algorithme de Décryptage

**Part 1:**
```
Encryption: input -> REVERSE -> ROT13 -> XOR KEY_1 -> D_1
Decryption: D_1 -> XOR KEY_1 -> ROT13 -> REVERSE -> flag_part1
```

**Part 2:**
```
Encryption: input[i] -> SWAP -> (REVERSE_BITS si i impair) -> XOR KEY_2 -> D_2[i]
Decryption: D_2[i] -> XOR KEY_2 -> (REVERSE_BITS si i impair) -> SWAP -> flag_part2[i]
```

---

## Solver

```python
#!/usr/bin/env python3

def rot13(c):
    if 'a' <= c <= 'z':
        return chr((ord(c) - ord('a') + 13) % 26 + ord('a'))
    elif 'A' <= c <= 'Z':
        return chr((ord(c) - ord('A') + 13) % 26 + ord('A'))
    return c

def swap_nibbles(x):
    return ((x << 4) | (x >> 4)) & 0xFF

def reverse_bits(x):
    r = 0
    for _ in range(8):
        r = (r << 1) | (x & 1)
        x >>= 1
    return r & 0xFF

# Données extraites
D_1 = [0x91, 0xaf, 0xac, 0xff, 0xa9, 0xa0, 0xa8, 0xff, 0xa9, 0xac, 0xbe]
D_2 = [0xfb, 0x69, 0xcb, 0xc5, 0x7b, 0xcf, 0x4a, 0x62, 0x1e, 0xe9, 0x5b]
KEY_1 = 0xCE
KEY_2 = 0x0D

# Part 1: XOR -> ROT13 -> REVERSE
part1_temp = ""
for b in D_1:
    xored = b ^ KEY_1
    part1_temp += rot13(chr(xored))
part1 = part1_temp[::-1]

# Part 2: XOR -> REVERSE_BITS (si impair) -> SWAP
part2 = ""
for i, b in enumerate(D_2):
    x = b ^ KEY_2
    if i % 2 == 1:
        x = reverse_bits(x)
    x = swap_nibbles(x)
    part2 += chr(x)

print(f"Securinets_fst{{{part1}{part2}}}")
```
